# claude-mod-handoff-nudge

Offers `/handoff-journal` or `/handoff-local` above the prompt when the context passes 60% and 85%, or the session runs past 3 hours. These are skills you must have yourself.

## Install

```bash
claude plugin marketplace add smhasan-yad/claude-mod-handoff-nudge
claude plugin install handoff-nudge@claude-mod-handoff-nudge
```

A new chat or /reload-plugins picks it up. Written for the Windows desktop app and terminal (Claude Code mods API); not tested elsewhere.
